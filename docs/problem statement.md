# Problem Statement

| Project No. | Project Title | Problem Statement |
|---|---|---|
| P_178 | Vehicle Health Monitoring System Using CAN | The system uses a STM32 development board to interface with multiple sensors, including a DHT11 temperature sensor and a vibration sensor. |
|  |  | Sensor data is processed by the transmitter node (Tx) and sent via the CAN protocol to the receiver node (Rx), which provides real-time insights into the vehicle’s performance through visual indicators and alarm. |
